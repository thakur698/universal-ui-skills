# Mobile UI

## Priorities

- thumb reachability
- safe areas
- touch targets
- readable text
- keyboard behavior
- loading feedback
- navigation clarity
- platform conventions

## Avoid desktop shrinkage

Recompose mobile interfaces rather than shrinking desktop layouts.

## Touch

Important controls should have comfortable hit targets and clear pressed states.

## System behavior

Respect:
- status/navigation areas
- system theme when supported
- text scaling/accessibility
- reduced motion when supported
