# Security

## Strict Rules

**NEVER commit:**
- API keys
- access tokens
- OAuth secrets
- private credentials
- proprietary customer assets
- private design files

External integrations must use user-provided credentials outside the repository (e.g., through environment variables or secure agent storage). 

If you are contributing an example, ensure no private data is accidentally included.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting on https://github.com/thakur698/universal-ui-skills/security/advisories/new and include the affected path and reproduction steps. Expect an initial response within a few days.
