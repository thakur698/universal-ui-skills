# Anti-Slop Standard

The purpose of this document is to make visual review concrete.

## Level 0 — Broken

Examples:
- clipping
- overflow
- unreadable text
- inaccessible controls
- broken interaction

Must fix immediately.

## Level 1 — Generic

Examples:
- default component library styling
- repetitive cards
- generic SaaS composition
- generic gradients
- no product-specific visual identity

Must redesign.

## Level 2 — Polished but interchangeable

Everything works, but the design could belong to many products.

Improve:
- composition
- typography
- visual metaphor
- imagery
- interaction language
- hierarchy

## Level 3 — Distinctive

The interface clearly belongs to the product and its users.

## Level 4 — Excellent

The UI is distinctive while remaining:
- usable
- accessible
- responsive
- maintainable
- visually coherent

Target Level 4 for major product surfaces.
