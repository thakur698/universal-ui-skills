# Public Release Checklist

Before promoting the repository:

- [ ] Replace all placeholder GitHub usernames/URLs
- [ ] Confirm README installation commands use the real repository URL
- [ ] Add repository description
- [ ] Add topics
- [ ] Confirm MIT license
- [ ] Confirm no API keys or secrets
- [ ] Confirm no proprietary assets
- [ ] Verify skill frontmatter
- [ ] Run repository validation
- [ ] Check every README link
- [ ] Add at least one example
- [ ] Add a social preview image
- [ ] Create a first release/tag
- [ ] Add a clear contribution guide
- [ ] Add issue templates
- [ ] Add GitHub Actions validation
