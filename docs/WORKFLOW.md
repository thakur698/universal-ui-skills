# Production UI Workflow

## 1. Brief

Write:
- audience
- user goal
- platform
- brand/product tone
- constraints

## 2. Direction

Create a visual direction before generating multiple screens.

## 3. System

Create tokens and core components.

## 4. Compose

Build one representative screen first.

## 5. Expand

Apply the established language to related screens.

## 6. Motion

Add purposeful motion after the static hierarchy works.

## 7. Responsive/accessibility

Validate platform behavior.

## 8. Visual QA

Review screenshots/goldens.

## 9. Anti-slop

Ask whether the result looks interchangeable with another AI-generated product.

## 10. Polish

Fix the highest-impact visual problems first.
