# Asset Guidelines

Follow this workflow for generating or sourcing visual assets (icons, illustrations, images).

## 1. Asset Workflow
1. **Define Purpose**: What is the asset doing?
2. **Define Dimensions**: Exact size and aspect ratio.
3. **Define Visual Style**: Must match the product design direction.
4. **Source/Generate**: Find or create the asset.
5. **Review Consistency**: (See below)
6. **Normalize**: Fix bounds, paths, bounding boxes.
7. **Name Semantically**: e.g., `ic_menu`, `img_hero_background`.
8. **Integrate Centrally**: Add to asset system.
9. **Check Licensing**: Ensure open-source/commercial clearance.

## 2. Consistency Review
When introducing a new asset, check it against the existing ones:
- **Visual Weight**: Is it too bold or too thin?
- **Lighting / Perspective**: Do shadows match the global light source? Are illustrations all flat or all 3D?
- **Palette**: Does it use the brand colors or random colors?
- **Detail**: Is it too detailed compared to the rest of the minimal UI?
