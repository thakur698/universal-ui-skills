# Motion Guidelines

Motion is communication.

## Levels of Motion

1. **Micro**: Tiny feedback loops (button press, toggle, checkbox). Fast (100-150ms).
2. **Standard**: State transitions (modals, routes, lists). Smooth and directional (200-300ms).
3. **Hero**: Major events (onboarding reveals, success states). Expressive.

## Motion Checklist
For every non-trivial animation:
- [ ] What changed?
- [ ] Why does the user need to notice?
- [ ] What is the visual focal point?
- [ ] Does the motion delay interaction? (It shouldn't)
- [ ] Is there a reduced-motion fallback?
