# Responsive Layout Checklist

Do not just "scale down." Meaningfully adapt the composition.

## General
- [ ] No horizontal scrolling on the main page body.
- [ ] Max-widths are applied to prevent infinite stretching on ultra-wide screens.
- [ ] Line lengths for reading text are constrained (60-80 characters).

## Mobile Adaptations
- [ ] Multi-column grids stack into a single column.
- [ ] Horizontal navigation bars collapse into bottom navigation or a hamburger menu.
- [ ] Complex data tables convert to list views or horizontally-scrollable cards.
- [ ] Primary actions (CTAs) are reachable by the thumb (anchored to bottom).
- [ ] Touch targets are at least 44x44pt.
- [ ] Inputs remain visible when the virtual keyboard appears.
- [ ] Device safe areas (notches, home indicators) are respected.
- [ ] Text scales gracefully with OS accessibility settings.
