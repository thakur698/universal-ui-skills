# Accessibility Evaluation (Basic)

## Visibility
- [ ] Do text elements meet the 4.5:1 minimum contrast ratio?
- [ ] Do UI elements and icons meet the 3:1 minimum contrast ratio?
- [ ] Are focus rings clearly visible when navigating via keyboard?

## Semantics
- [ ] Are semantic HTML tags or correct platform accessibility traits used?
- [ ] Do all form inputs have associated labels (not just placeholders)?
- [ ] Is state communicated through more than just color (e.g. icon + text for errors)?

## Interaction
- [ ] Are touch targets large enough (44x44pt or 48x48dp)?
- [ ] Can every interactive element be reached and operated via keyboard?
