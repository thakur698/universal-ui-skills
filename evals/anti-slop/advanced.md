# Anti-Slop Evaluation (Advanced)

Run this checklist against a complete product workflow or screen.

## Identity & Context
- [ ] Could this interface belong to 20 unrelated products?
- [ ] Which visual decisions are uniquely specific to this product's domain?

## Component Variation
- [ ] Is the UI over-reliant on the default state of a generic component library?
- [ ] Do data-heavy views use appropriate density rather than padded consumer layouts?

## Visual Noise
- [ ] Can you remove background colors, glassmorphism, or glow effects without losing the hierarchy?
- [ ] Is the screen memorable without any decorative effects?
- [ ] Is every single metric or label forced into a badge/pill?
