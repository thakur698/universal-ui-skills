# Anti-Slop Evaluation (Basic)

Run this checklist against a completed UI component or screen.

## Structure
- [ ] Is there an alternative to a basic card layout that makes more sense for this content?
- [ ] Are elements arbitrarily floating or symmetrically spaced without reason?

## Styling
- [ ] Are shadows doing meaningful depth-separation work, or just decoration?
- [ ] Is the primary brand color used purposefully instead of default purple/blue?
- [ ] Are border radii consistent and appropriate for the tone?

## Content
- [ ] Are icons used to support labels rather than acting as pure decoration?
- [ ] Is the typography hierarchy clear without relying on heavy colors?
