# Universal UI Skills Benchmarks

This directory contains the formal A/B evaluation suite for measuring UI quality across real-world product scenarios.

We test across 6 major domains:
1. Flutter Onboarding (`01-flutter-onboarding.md`)
2. Web Landing Page (`02-web-landing-page.md`)
3. Mobile Dashboard (`03-mobile-dashboard.md`)
4. Ecommerce Storefront (`04-ecommerce-storefront.md`)
5. Game UI (`05-game-ui.md`)
6. React SaaS (`06-react-saas.md`)

Each evaluation measures agents against the strict criteria defined in `rubric.md` while adhering to the constraints in `methodology.md`.
