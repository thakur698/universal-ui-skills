"Design a marketing and technical documentation portal for an open-source distributed time-series database. The audience is site reliability engineers (SREs) and database architects. ---

## Required Evidence Contract
1. **Interactive Query Visualizer**: Functional latency comparison under different read/write loads.
2. **Topology Diagram**: Clear architectural hierarchy (ingest node -> WAL -> storage tier).
3. **Copyable Snippets**: One-click copy interaction with visual confirmation for CLI setup.
4. **Accessible Theme & Hierarchy**: Monospace code blocks with strict WCAG AA contrast.
5. **Mobile Responsiveness**: Clean collapse of wide telemetry tables into readable mobile views.
