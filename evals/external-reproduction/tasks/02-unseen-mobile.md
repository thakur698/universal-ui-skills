# Unseen Task 02: Emergency Telehealth Clinical Mobile Flow

## Status: PENDING REPRODUCTION

## Task Brief (External / Out-of-Distribution)
"Design a rapid triage and tele-consultation mobile interface for rural emergency paramedic responders. The UI must work in high-stress, low-connectivity field environments with high-contrast critical triage color coding (Triage Red/Yellow/Green), one-thumb rapid vital entry, audio recording toggle, and offline synchronization status."

---

## Required Evidence Contract
1. **Critical Triage Coding**: Immediate visual hierarchy prioritizing urgent patient vitals.
2. **One-Thumb Interaction**: Primary emergency actions reachable in bottom 40% of viewport.
3. **High-Stress Contrast**: Strong WCAG AAA contrast for outdoor/direct-sunlight readability.
4. **Offline Resilience**: Clear indicators for cached local data vs. synced cloud state.
5. **Touch Target Size**: Minimum 48x48px interactive touch targets for gloved paramedic operation.
