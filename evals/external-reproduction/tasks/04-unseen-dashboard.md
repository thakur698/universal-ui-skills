# Unseen Task 04: Industrial Autonomous Fleet Telemetry Dashboard

## Status: PENDING REPRODUCTION

## Task Brief (External / Out-of-Distribution)
"Design a dense operational control room dashboard for monitoring a fleet of 50 autonomous mining haul trucks. The UI must display live geofence status, battery/payload levels, alert priority queues with acknowledgment interactions, sub-second telemetry feeds, and a dark cockpit mode optimized for multi-monitor NOC setups."

---

## Required Evidence Contract
1. **High Visual Density**: Compact, scannable data grids without excessive whitespace padding.
2. **Alert Severity Hierarchy**: Urgent collision/fault alerts visually distinct from routine diagnostic logs.
3. **Interactive Fleet Filter**: Filter trucks by operational status (Active, Charging, Maintenance, Critical).
4. **Cockpit Contrast**: Strict dark palette with muted backgrounds and high-contrast telemetry indicators.
5. **Keyboard / Focus Traversal**: Quick alert acknowledgment accessible via keyboard shortcuts or rapid clicks.
