# Responsive Evaluation (Mobile)

## Layout Shifts
- [ ] Do multi-column layouts stack into a single column?
- [ ] Is horizontal scrolling prevented for the main page body?
- [ ] Are horizontal tables converted to lists or card-based views?

## Interaction & Ergonomics
- [ ] Are primary actions easily reachable by thumb (anchored to the bottom or easily accessible)?
- [ ] Are tap targets at least 44x44pt?
- [ ] Is the virtual keyboard covering essential inputs?

## Context
- [ ] Do elements respect the device's safe areas (notch, dynamic island)?
- [ ] Does text scale gracefully when OS accessibility text settings are increased?
