# Responsive Evaluation (Web)

## Fluidity & Constraints
- [ ] Does the UI scale fluidly between standard breakpoints without horizontal scroll?
- [ ] Are max-widths defined so the UI doesn't stretch infinitely on ultrawide monitors?

## Density & Composition
- [ ] Is the available horizontal space used efficiently (e.g., sidebars instead of stacked content)?
- [ ] Are secondary navigation or panels exposed on large screens rather than hidden in hamburgers?
- [ ] Is line length for reading text constrained to 60-80 characters?
