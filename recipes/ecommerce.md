# Recipe: E-commerce Experience

When tasked with building an e-commerce app/site, orchestrate the following workflow:

## 1. Tool Discovery
- Check for Image optimization libraries (e.g., Next/Image).
- Check for accessibility scanning tools (Axe) - crucial for e-commerce compliance.

## 2. Design Direction
- **Goal**: Product discovery, seamless checkout, trust.
- **Typography**: Clean, readable fonts for descriptions; high-contrast price tags.
- **Imagery**: Product photography must be the focal point. UI should recede.

## 3. Component System
- Product cards (image, title, price, CTA).
- Filter/Facet sidebars.
- Sticky Add to Cart bars for mobile.

## 4. Motion
- **Micro**: Cart icon "bounces" when an item is added.
- **Standard**: Smooth image carousels; expanded image zoom.

## 5. Visual QA
- Ensure product images do not break layout aspect ratios.
- Verify primary CTAs are highly visible and pass contrast checks.
