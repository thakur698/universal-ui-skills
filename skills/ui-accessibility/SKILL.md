# Accessibility

Check:
- readable text
- sufficient contrast
- focus visibility
- keyboard navigation on web
- touch target size on mobile
- semantic labels
- error messaging
- logical reading order
- form labels
- disabled/loading semantics
- text scaling/dynamic type
- reduced motion

Do not rely only on color to communicate state.

Accessibility is part of visual quality, not a separate final checklist.
