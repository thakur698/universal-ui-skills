# UI Design Direction

## Required reasoning

Decide:
- What should the interface feel like?
- What should the user notice first?
- What visual metaphors belong to this product?
- What should the interface deliberately NOT look like?

## Define

### Typography
- display style
- body style
- numeric/data treatment
- hierarchy
- line height
- weight usage

### Color
Use semantic roles:
- background
- surface
- elevated surface
- text primary
- text secondary
- border/divider
- brand
- interactive
- success
- warning
- error

Do not choose colors just because they are popular.

### Shape
Define:
- corner-radius families
- border language
- container geometry
- icon container style

### Depth
Choose deliberately:
- flat
- layered
- subtle elevation
- atmospheric
- outlined

Do not apply shadows to every element.

### Composition

Specify:
- primary visual anchor
- primary action
- supporting content
- secondary actions
- empty-space strategy

Avoid making every section visually equal.
